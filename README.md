# مصاريفي — Masarify

تطبيق Android شخصي لإدارة المصاريف، مبني بـ Kotlin وJetpack Compose. التصميم المعتمد: **النموذج 1** مع ثيم أخضر/أزرق ووضع فاتح/ليلي/حسب النظام. **العملة الثابتة: الريال القطري (ر.ق).**

## الموجود في v0.2

- قاعدة Room محلية؛ لا يحتاج التطبيق حسابًا أو إنترنت.
- حسابات متعددة وضبط الرصيد.
- مصروف ودخل وتحويل بين الحسابات، مع تحديث الأرصدة.
- قائمة العمليات والبحث والحذف مع عكس أثر الحذف على الرصيد.
- خطة راتب والتزامات وهدف ادخار، وحساب تقديري للمتاح بأمان.
- تقارير الشهر حسب التصنيف.
- ثيم أخضر أو أزرق، وفاتح أو ليلي أو حسب النظام.
- Widget للشاشة الرئيسية يعرض المتاح بأمان ويفتح التطبيق.
- قارئ أولي للرسائل الجديدة، مغلق افتراضيًا، يحلل محليًا وينشئ مسودة للمراجعة.
- إشعار عند رصد عملية أو راتب، مع منع تكرار الرسالة بواسطة بصمة SHA-256.
- **واجهة معاد تصميمها** بمسافات آمنة أعلى الشاشة وهرمية أوضح.
- **مساعد مصاريفي**: تحليل مالي محلي كامل يعمل بدون إنترنت، مع مساعد سحابي اختياري.

## الذكاء الاصطناعي

### الوضع المحلي (الافتراضي، بدون إنترنت)

يجري كل الحساب داخل الجهاز من البيانات المسجلة في التطبيق:

- المتاح بأمان والمصروف اليومي الموصى به.
- أكبر بنود الصرف ونسبها، واقتراح توفير 10% من أكبر بند.
- اكتشاف عملية استثنائية أكبر من المعتاد.
- مقارنة معدل الصرف اليومي بالخطة.
- توقع مصروف نهاية الدورة من وتيرة الصرف.
- أسئلة سريعة جاهزة: كم باقي؟ وين أصرف أكثر؟ كم أقدر أوفر؟ توقع نهاية الشهر.

### الوضع السحابي (اختياري)

- يستخدم Gemini API بمفتاح المستخدم الشخصي.
- يُفعّل من: الإعدادات ← مساعد مصاريفي ← المساعد السحابي.
- المفتاح يُخزَّن على الجهاز فقط (DataStore) ولا يُكتب في السجلات ولا في Git.
- خيارات: الموديل، أسلوب الرد (بسيط/ودّي/تحليلي)، وإرسال الأرقام من عدمه.
- إذا كان «أشارك الأرقام» مقفولًا، يُرسل عدد العمليات ونسب التصنيفات فقط بدون مبالغ.
- إذا فشل الاتصال، يرجع التطبيق تلقائيًا للجواب المحلي مع ملاحظة الخطأ.

## غير مفعّل بعد

- Google Drive: يحتاج مشروع Google Cloud وOAuth. لا توجد مفاتيح في التطبيق ولا بيانات مرفوعة.
- قوالب بنوك مخصصة: قارئ SMS الحالي عام ويحتاج تجربة على رسائل بنك المستخدم الحقيقية قبل الاعتماد عليه.
- النسخ الاحتياطي المحلي JSON والاستعادة.
- تعديل العمليات والتصنيفات المخصصة والالتزامات التفصيلية.

## الخصوصية

- لا توجد تحليلات أو تتبع.
- إذن `RECEIVE_SMS` اختياري، ولا يطلب التطبيق `READ_SMS` في هذه المرحلة.
- لا يُحفظ نص الرسالة؛ تُحفظ العملية المستخرجة وبصمتها فقط.
- التحليل المحلي لا يرسل أي شي.
- المساعد السحابي لا يشتغل إلا بتفعيل المستخدم ومفتاحه.
- الالتزام بقواعد الرقابة عند نشر التطبيق على Google Play لا ينطبق الآن لأن الاستخدام شخصي وتوزيع APK مباشر.
