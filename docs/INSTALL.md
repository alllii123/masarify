# مصاريفي — التثبيت والتحديث والنسخ الاحتياطي

الإصدار الحالي: **v0.3.0**

## ١) التحديث صار طبيعي — لا تحذف التطبيق

كان السبب القديم لرسالة «التطبيق ليس مثبتًا» أن النسخة التجريبية ونسخة الإصدار كانتا **بمفتاحين مختلفين**.

من v0.3.0 وصاعدًا: **نفس مفتاح التوقيع + نفس معرّف الحزمة `com.masarify.app`**.

معناه:

- تثبيت النسخة الجديدة فوق القديمة يعمل **كتحديث عادي**.
- **ما تحتاج تحذف التطبيق**.
- **بياناتك تبقى** كما هي.

> استثناء واحد: لو عندك الآن نسخة قديمة موقّعة بمفتاح Android Debug القديم (v0.2.0-debug فقط)، فهذه آخر مرة تحتاج تحذفها. بعدها كل التحديثات مباشرة.

## ٢) التثبيت

1. حمّل من متصفح الجوال مباشرة:
   https://github.com/alllii123/masarify/releases/latest
2. اختر **`Masarify-v0.3.0-release.apk`** (2.1 ميجابايت).
3. اضغط تثبيت. لو ظهر تحذير Play Protect: **تثبيت بالرغم من ذلك**.

لا ترسل الملف عبر واتساب أو تيليجرام — هذولا يفسدان ملفات APK.

## ٣) Google Drive: نسخة احتياطية

**للحفظ:**

1. الإعدادات ← **النسخ الاحتياطي والاستعادة**
2. اضغط **«نسخة احتياطية»**
3. تفتح قائمة المشاركة ← اختر **Drive**
4. احفظ الملف. اسمه مثل: `masarify-backup-2026-11-07_14-30.json`

**على الجوال الجديد:**

1. ثبّت التطبيق.
2. الإعدادات ← استعادة.
3. اختر الملف من Drive.
4. التطبيق يعرض محتوى الملف، ثم تختار:
   - **دمج** — يضيف البيانات على الموجود
   - **استبدال الكل** — يحذف الحالي ويستعيد الملف

**ملاحظات:**

- لا يحتاج OAuth ولا حساب Google Cloud.
- مفتاح الذكاء الاصطناعي **لا** يُحفظ في النسخة الاحتياطية.
- الاحتفاظ بالنسخ: التطبيق يحفظ آخر 5 ملفات محليًا.

## ٤) المساعد الذكي

| الوضع | يشتغل بدون إنترنت | يرسل بياناتك |
|---|---|---|
| **محلي** | ✅ | لا شيء إطلاقًا |
| **تلقائي** | نعم (محلي) | فقط لو أضفت مفتاح |
| **سحابي** | لا | الأرقام حسب خيار «أشارك الأرقام» |

- تبديل الوضع من **شاشة المساعد** مباشرة (شرائح أعلى الشاشة) أو من الإعدادات.
- الموديل الافتراضي الآن `gemini-flash-latest`.
- لو رجّع خطأ، اضغط **«تحديث الموديلات»** ثم اختر موديلًا من القائمة الظاهرة.
- **الوضع المحلي يجاوب دائمًا** حتى لو فشل الاتصال.

## ٦) الحل المضمون لو فشل التثبيت

```bash
adb install -r Masarify-v0.3.0-release.apk
```

`-r` يعني استبدال النسخة القديمة مع الحفاظ على البيانات.

## ٧) البناء من المصدر

```bash
mkdir -p /path/to/sdk && export ANDROID_HOME=/path/to/sdk
# أنشئ keystore.properties محليًا بمفاتيحك (غير مرفوع في Git)
./gradlew testDebugUnitTest assembleRelease
```

بدون `keystore.properties` يبني المشروع APK غير موقّع — وهو مقصود حتى لا تُرفع مفاتيحك.
