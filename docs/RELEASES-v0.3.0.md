## v0.3.0 — التثبيت فوق القديم، Google Drive، وإصلاح المساعد

### 1) التثبيت صار يتحدّث فوق القديم
السبب السابق لرسالة «التطبيق ليس مثبتًا» أن نسخة debug ونسخة release كانتا بمفتاحين ومعرّفين مختلفين.
الآن **النسختان بنفس معرّف الحزمة `com.masarify.app` ونفس مفتاح التوقيع**، فتحميل الإصدار الجديد يعمل كتحديث عادي فوق القديم **بدون حذف التطبيق وبدون فقدان البيانات**.

### 2) Google Drive — نسخ احتياطي واستعادة
- زر «نسخة احتياطية» ينتج ملف JSON كاملًا ثم يفتح قائمة المشاركة: اختر **Drive** ليُحفظ في حسابك.
- على الجوال الجديد: ثبّت التطبيق ← الإعدادات ← استعادة ← اختر الملف من Drive.
- طريقتان للاستعادة: **دمج** (يضيف الناقص فقط) أو **استبدال** (يحذف الحالي).
- لا يحتاج OAuth ولا مشروع Google Cloud ولا أي أسرار داخل التطبيق.
- مفتاح الذكاء الاصطناعي **لا يُصدَّر** في النسخة الاحتياطية أبدًا.

### 3) إصلاحات المساعد
- **الموديل القديم `gemini-2.0-flash` كان منتهيًا**، وهذا سبب الـTimeout. الافتراضي الآن `gemini-flash-latest`، والتطبيق يجرّب عدة أسماء تلقائيًا.
- زر **«تحديث الموديلات»** يجلب الموديلات المتاحة على مفتاحك فعليًا ويعرضها كاختيارات.
- **مبدّل وضع واضح** في شاشة المساعد: محلي / تلقائي / سحابي.
- **المحلي صار يجاوب دائمًا**؛ كان ينهار عند قسمة على صفر ويرجع شاشة ساكنة.
- لو فشل السحابي، تُعرض رسالة الخطأ الحقيقية + جواب محلي بدل الانتظار.
- زر الإرسال من لوحة مفاتيح الجوال يعمل الآن.

### التثبيت
حمّل `Masarify-v0.3.0-release.apk` (2.1 MB) وثبّته فوق نسختك الحالية.
