# v0.4.5 — يفهم اللهجة + ذكاء محلي أقوى + استجابة سحابية ثابتة + مجموعك في الواجهة

## 1) يفهم العامية (بدل «لازم أكتب أمر معين»)
- **تطبيع عربي** (`ArText`): أ/إ/آ ← ا، ة ← ه، ى ← ي، وحذف التشكيل.
  فـ«اضف» = «أضف»، «قهوه» = «قهوة»، «الى» = «إلى».
- أفعال عامية مضافة: صرفت، دفعت، شريت، اشتريت، خذ، اخذت، طلعت، كلفني، تعشيت، تغديت،
  فطرت، شربت، استلمت، بليت.
- مطابقة **كلمة كاملة** لا جزء من كلمة، فلا تتداخل الكلمات.
- **ثلاث حالات بدل حالتين**:
  - أمر صريح («صرفت 40 بنزين») ← ينفّذ فورًا.
  - صياغة مفهومة بلا فعل («المصروف 40 مطاعم») ← يظهر زر **تأكيد/إلغاء**، لا تسجيل صامت.
  - سؤال أو نية مستقبلية («بصرف بكرة»، «كم صرفت؟») ← لا تنفيذ أبدًا.

## 2) الذكاء المحلي أقوى
- مصنّف نوايا (`LocalTopic`) بـ 11 موضوعًا: المجموع، المتاح، الصرف، التصنيفات، الادخار،
  التوقع، الراتب، الدخل، المقارنة، النصيحة، المساعدة.
- **لا يعتذر أبدًا**: أي سؤال غير مفهوم يُجاب بملخص مالي كامل بدل «ما فهمت».
- ردود أغنى: الرصيد + المتاح + الالتزامات + الادخار + متوسط اليوم + أكبر بند + توقع النهاية.
- إضافة `projectedLeftover` و`burnRatio` لحساب ما سيبقى لو استمر بنفس المعدل.

## 3) ليش السحابي يستجيب مرات ومرات لا
السبب الفعلي كان في سياسة إعادة المحاولة، لا في الشبكة:
- **429 (حصة) كان يُعامَل كخطأ حتمي** فيوقف كل السلسلة. الآن ينتقل للموديل التالي.
- **500/502/503/504 كان يُعامل كخطأ حتمي** أيضًا. الآن يُعاد ثم ينتقل للموديل التالي.
- كل موديل يُجرّب **مرتين** بفاصل 0.7 ثانية.
- 401/403 فقط هي الحتمية فعلًا (مفتاح/مشروع) وتوقف فورًا برسالة واضحة.
- الموديل الأول صار `gemini-flash-latest` لأنه alias لا يتقاعد، بدل `2.5-flash-lite`
  الذي أعلنت Google تقاعده 2026-10-20.

## 4) الواجهة: مجموعك والمتاح بأمان
- في بطاقة «المتاح بأمان» صار يظهر سطرًا صريحًا: **مجموعك في كل الحسابات**.
- تحتها صف ثلاث بطاقات: **مجموعك** (بلون مميز)، **المتاح بأمان**، **يوميًا**.
