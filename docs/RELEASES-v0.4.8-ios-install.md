# تثبيت iOS من ويندوز — إضافة v0.4.8

## المشكلة
المستخدم على ويندوز بحساب Apple مجاني، وما فهم كيف يثبّت نسخة iOS.
الجواب القديم «افتح Xcode على Mac» غير عملي — يحتاج جهازًا لا يملكه.

## الحل المتبع
1. **بناء تلقائي في السحابة** — `.github/workflows/ios.yml` يبني على `macos-15`
   وينتج **IPA غير موقّع** كـ Artifact (مدة حفظ 90 يومًا). لا يحتاج Mac.
2. **توقيع على ويندوز** — Sideloadly + Apple ID المجاني. التطبيق يعمل 7 أيام
   ثم يُعاد توقيعه بدقيقة، والبيانات تبقى.
3. **دليل عربي كامل** — `ios/HOW-TO-INSTALL-WINDOWS.md` بست خطوات،
   مع جدول أخطاء شائعة وحلولها.
4. **`ios/project.yml`** — مصدر بديل لتوليد المشروع عبر xcodegen داخل CI،
   فيقلّل احتمال فشل البناء بسبب ملف pbxproj.

## إصلاحات كود iOS في هذه الدفعة
- **مخططات التقارير**: `Chart(_:id:)` لا يقبل KeyPath لمصفوفة tuples؛
  استُبدل بـ `Chart { ForEach(...) }` في المخطط الدائري واليومي.
- إزالة متغير غير مستخدم في `AssistantEngine`.

## ملاحظة أمانة
الـ IPA الناتج **غير موقّع بقصد** — لا يمكن ولا يجوز تضمين شهادة توقيع
في المستودع. التوقيع يُنتج هوية خاصة بكل مستخدم.
