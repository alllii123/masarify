# الإصدارات

## v0.1.0 — نسخة اختبار أولى

- تطبيق Android شخصي باسم «مصاريفي».
- التصميم المعتمد: النموذج 1.
- حفظ محلي Room دون حساب أو إنترنت.
- حسابات ومصروف ودخل وتحويل وبحث وحذف.
- خطة راتب والتزامات وادخار وحساب المتاح بأمان.
- تقارير شهرية حسب التصنيف.
- ثيم أخضر وأزرق، وفاتح وليلي وحسب النظام.
- Widget أساسي.
- قارئ SMS عام للرسائل الجديدة مع مراجعة قبل الحفظ وإشعار للعمليات والراتب.
- ستة اختبارات وحدة ناجحة.

### ملاحظات مهمة

- هذه نسخة Debug للتجربة، وليست الإصدار النهائي.
- Google Drive غير مفعّل ويحتاج Google Cloud وOAuth.
- قارئ SMS يحتاج تخصيصًا على قوالب بنك المستخدم قبل الاعتماد عليه.
- لا توجد بيانات حقيقية أو مفاتيح سرية في المستودع.
