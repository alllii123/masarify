# محفظتي — نسخة iOS / iPadOS

نسخة أصلية بـ **SwiftUI** داخل نفس المستودع، بنفس الإصدار **0.4.8** وبنفس المنطق المالي.

> **مهم:** iOS لا يسمح بتثبيت تطبيق من ملف جاهز مثل أندرويد. الملف يجب أن يُوقَّع
> بهوية Apple خاصة بك. لذلك البناء يحدث في السحابة (GitHub Actions على macOS)،
> والتوقيع يحدث على جهازك (ويندوز بـ Sideloadly). لا تحتاج Mac.

---

## 📱 التثبيت بدون Mac (ويندوز + آيفون)

اتبع **[HOW-TO-INSTALL-WINDOWS.md](HOW-TO-INSTALL-WINDOWS.md)** — دليل كامل خطوة بخطوة.

الخلاصة: ابنِ الـ IPA من تبويب Actions على GitHub ← وقّعه بـ Sideloadly بحساب Apple ID المجاني.
ما تحتاج Mac ولا حساب مدفوع.

## التشغيل على Mac

```bash
git clone https://github.com/alllii123/masarify.git
cd masarify/ios
open Mahfazati.xcodeproj
```

1. اختر Team في **Signing & Capabilities** (حسابك المجاني يكفي).
2. اختر الجهاز (iPhone أو iPad) واضغط **Run**.

## توليد المشروع من الصفر

لو تبي إعادة توليد `Mahfazati.xcodeproj` (مثلاً بعد إضافة ملفات):

```bash
brew install xcodegen
cd ios && xcodegen generate
```

`project.yml` هو المصدر، والمشروع المولّد يُلتزم في المستودع للسهولة.

- **الحد الأدنى:** iOS 17.0
- **الأجهزة:** iPhone و iPad (`TARGETED_DEVICE_FAMILY = 1,2`)
- **المعرّف:** `com.mahfazati.app`
- **الإصدار:** 0.4.8 (build 10)

## ما لا يوجد في iOS

- **قراءة رسائل SMS البنكية**: iOS لا يسمح لأي تطبيق بقراءة الرسائل. هذا قيد نظام لا يمكن تجاوزه.
  البديل: استيراد نسخة احتياطية، أو إدخال العملية عبر المساعد/النموذج.
- **الودجت**: ممكن لاحقًا عبر WidgetKit، لكنه يحتاج extension منفصل.
- **التحديث الذاتي للـ APK**: لا معنى له على iOS — التحديثات عبر App Store أو TestFlight.

## التحقق قبل البناء

شيفرة المنطق (بدون واجهة) تحقّقت فعليًا على لينكس بـ Swift 6.0.3:

```
38 اختبارًا — 0 فشل
```

تشمل: تنسيق العملة، الأرقام العربية، تطبيع الحروف، 7 صيغ أوامر عامية،
7 أسئلة لا تُنفّذ، 3 نوايا مستقبلية لا تُنفّذ، دورة نسخ احتياطي كاملة،
والتأكد أن المفتاح غير مضمّن في أي ملف.

أخطاء حقيقية اكتُشفت بهذه الاختبارات وأُصلحت:
1. **الشدة ( ّ ) لم تكن تُحذف** ⇒ «عدّل» لا تساوي «عدل»، فالتعديل كان يُفهم كإضافة.
2. **المسافة قبل «ألف»** كانت تُفشل مضاعف الألف ⇒ «2 ألف» تُقرأ 2 ريال بدل 2000.
